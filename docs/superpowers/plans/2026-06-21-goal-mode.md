# Goal Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a working Goal Mode that creates visible plans/todos, delegates work to predefined subagents, records progress/activity, supports stop, and exposes the workflow in Web UI.

**Architecture:** Add a focused `internal/goal` package for `GoalRun`, `GoalTodo`, `GoalActivity`, JSON persistence, and a sequential runner. Reuse existing subagent manager for actual delegation, expose project-scoped goal APIs from `api/server`, then add a Goal mode in the existing React app with a Goal Activity Panel.

**Tech Stack:** Go + Gin backend, JSON persistence under UUAgent data directories, existing subagent manager, React + TypeScript + Vitest frontend, existing `scripts/test.ps1` validation.

---

## File Structure

- Create `internal/goal/types.go`: goal domain types and statuses.
- Create `internal/goal/store.go`: JSON-backed goal store with create/list/get/update/stop operations.
- Create `internal/goal/runner.go`: deterministic MVP runner that creates a plan, delegates todos to configured subagents, records activities, supports cancellation.
- Create `tests/goal/store_test.go`: unit tests for goal persistence and state transitions.
- Create `tests/goal/api_test.go`: API tests for create/list/get/stop and completed run activity.
- Modify `internal/config/config.go`: default built-in subagent profiles `planner`, `explorer`, `builder`, `tester`, `reviewer`.
- Modify `internal/subagent/manager.go`: expose enough result/status behavior if needed by goal runner.
- Modify `api/server/server.go`: register and implement goal endpoints.
- Modify `internal/agent/agent.go`: expose `delegate_task` tool using the existing subagent manager, if tool registry currently lacks it.
- Modify `web/src/App.tsx`: add Chat/Goal mode toggle, goal creation, polling, plan/todo/activity panel, stop button.
- Modify `web/src/App.css`: style Goal Mode using current dark UI tokens/classes.
- Modify `web/src/App.test.tsx`: tests for Goal Mode UI, activity display, subagent activity, stop.
- Modify `docs/DEVELOPMENT_TODO.md`, `docs/TEST_TODO.md`, `docs/核心关注功能.txt`: mark Goal Mode MVP progress and test coverage.

## Task 5: Goal Runner TDD

**Files:**
- Create: `internal/goal/runner.go`
- Modify: `tests/goal/store_test.go` or create `tests/goal/runner_test.go`

- [x] **Step 1: Write failing runner tests**

Add tests named:

```go
func Test_Runner_Run_completes_goal_with_plan_todos_and_subagent_activities(t *testing.T)
func Test_Runner_Stop_cancels_goal_before_next_todo(t *testing.T)
```

For MVP, use a fake delegate function with deterministic outputs instead of a real LLM. Assert:
- planner activity is recorded
- todos are created before execution
- explorer/builder/tester/reviewer delegation activities are recorded
- completed todos contain result text
- final status is `completed`
- stop sets status `cancelled` and no further todos run

Expected RED: runner missing.

- [x] **Step 2: Implement runner**

Runner behavior:
1. Mark goal `planning`.
2. Create deterministic initial plan/todos from the goal:
   - Understand goal and inspect context (`planner`)
   - Explore relevant code (`explorer`)
   - Implement focused changes (`builder`)
   - Test and verify (`tester`)
   - Review completion (`reviewer`)
3. Mark goal `running`.
4. For each todo, call delegate function with assigned subagent ID and task text.
5. Append `delegate_started`, `delegate_completed`, `todo_started`, `todo_completed` activities.
6. Mark goal `completed` when all todos complete.
7. Respect stop/cancellation before each todo.

- [x] **Step 3: Verify runner tests pass**

Run:

```powershell
go test ./tests/goal -run Test_Runner -count=1
```

Expected GREEN.
